# 🛡️ OptiPrice Enterprise Analytics Portal

An enterprise-grade, data-driven Software-as-a-Service (SaaS) web application built to eliminate guessing in retail valuation matrices. This platform uses machine learning models trained on **115,000+ real-world historical store transactions** to calculate the most profitable product price points in real-time.

## ✨ Core System Features
- **Multi-Sector Optimization Pipelines:** Dynamically adjusts calculation variables for distinct markets including Premium Cosmetics, FMCG Packaged Foods, and General Merchandise.
- **Interactive Simulation Controls:** Instant parameter modulation tracking how box dimensions, package grams, customer satisfaction scores, and payment installment counts shift price thresholds.
- **Logistics Guardrails:** Hard-coded system caps aligned with actual national postal infrastructure rules (e.g., Correios 105cm package limits).
- **Secure Architecture:** Built-in corporate credential validation simulator to protect calculation logging systems.
- **Audit Sandbox:** Transparent database inspection module allowing managers to view underlying training tables.

## 🛠️ Technology Stack
- **Language:** Python 3.13
- **Frontend / Web UI:** Streamlit Framework
- **Machine Learning Core:** Scikit-Learn (Random Forest Regressor, Train-Test Split)
- **Data Engineering:** Pandas & NumPy
- **Environment Management:** UV Package Installer
